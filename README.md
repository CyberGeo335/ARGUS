# ARGUS

Репозиторий проекта ARGUS.

## Структура проекта

Дерево папок без каталогов, исключённых через `.gitignore`, и служебного каталога `.git/`:

```text
ARGUS/
├── prom_sys/
└── rnd/
    ├── notebooks/
    └── scripts/
```

- `prom_sys/` — пока пустой каталог.
- `rnd/` — исследовательские материалы и эксперименты.
- `rnd/notebooks/` — Jupyter-ноутбуки.
- `rnd/scripts/` — Python-скрипты.

## Локальные данные

Каталоги `data/` и `курсовая/` исключены из Git и не входят в дерево выше.
